## Arduino

### Build Your Own Arduino Arcade Cabinet

Crafting an arcade cabinet at home is now within reach with the Arduino UNO Q. This project involves assembling the cabinet, integrating a joystick and buttons, and setting up a display for classic games. Perfect for DIY enthusiasts, it combines creativity with technical skills.

**Source →** [projecthub.arduino.cc](https://projecthub.arduino.cc/)

### Build a DIY Mini Electronic Piano

Building a mini electronic piano with Arduino is a rewarding DIY project. You'll need an Arduino Nano, a 3D printed case, and touch sensors. Follow the steps to assemble, program, and test your piano, and explore potential modifications for a personalized touch.

**Source →** [instructables.com](https://www.instructables.com/How-to-Make-Mini-Electronic-Piano-Using-Arduino/)

### Build a Handheld Space Invaders Arcade

Creating a handheld Space Invaders arcade machine is a rewarding project for retro gaming fans. Using an Arduino Nano R4 and a 128x64 OLED display, this DIY project involves programming in C++ and assembling the components with detailed instructions, offering a nostalgic gaming experience.

**Source →** [threads.com](https://www.threads.com/@coreelectronics)

### Crafting a Miniature Aquatic World: DIY Table Top Aquarium

Building a tabletop aquarium is a fun and educational project. Gather materials like glass panels, silicone sealant, and a filtration system. Follow steps to assemble the base and frame, and integrate electronics for lighting. Learn about potential challenges and enjoy the aquarium's beauty.
