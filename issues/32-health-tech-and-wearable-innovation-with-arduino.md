## Arduino

### Make Sneakers Light Up with Arduino

Interactive sneakers are within reach using Arduino and NeoPixels. This project involves integrating motion sensors and programmable LEDs to create dynamic light patterns. Learn about the necessary components, assembly steps, coding, and power management to bring your wearable tech ideas to life.

**Source →** [projecthub.arduino.cc](https://projecthub.arduino.cc/)

### Build an Open-Source Spirometer

Creating a spirometer at home is now possible with an open-source design using the ESP32-POE-ISO and Sensirion SFM3300 Flow Sensor. This project is perfect for makers interested in health technology, offering a customizable and accessible way to measure tidal volume.

**Source →** [hackaday.io](https://hackaday.io/project/170446-open-source-spirometer-using-esp32)
