### **Project 1: Light-Up Arduino Sneakers**

*   **What It Is:** A project to build interactive sneakers that light up using Arduino and programmable LEDs.

*   **How It Works Technically:** The system uses motion sensors to detect movement. This sensor data is processed by an Arduino, which then triggers dynamic light patterns on NeoPixel LEDs integrated into the sneakers. The guide covers the coding and power management aspects of the build.

*   **Standout Details:**
    *   **Controller:** Arduino platform.
    *   **Sensors:** Motion sensors.
    *   **Outputs:** NeoPixels (programmable LEDs).
    *   **Other Covered Topics:** The project guide includes information on component selection, assembly steps, coding, and power management.

*   **Why Makers Care:** This is a hands-on wearable tech project. It provides a practical application for learning about integrating sensors and programmable LEDs, and managing power in a mobile, wearable form factor.

### **Project 2: Open-Source ESP32 Spirometer**

*   **What It Is:** A DIY, open-source spirometer designed for home construction. Its function is to measure tidal volume.

*   **How It Works Technically:** The device uses a flow sensor to measure the movement of air. This data is read and processed by an ESP32 board to calculate tidal volume.

*   **Standout Details:**
    *   **Controller:** ESP32-POE-ISO.
    *   **Sensor:** Sensirion SFM3300 Flow Sensor.

*   **Why Makers Care:** This project allows makers interested in health technology to build their own medical measurement device. Because it is an open-source design, it offers a customizable and accessible entry point into building health tech hardware.
